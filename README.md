# Two-Player Wordle 

A two-player Wordle game for the terminal, written in Java. 

## Project Goal
My friends and I like playing Hangman and Wordle, but each has issues. Hangman sometimes feels like just guessing random letters with little strategy, and Wordle gives only one puzzle a day with no way to play a match against a friend. 
We want a word game that is player-based, uses Wordle color clues, and can be played more than once a day. 

## MVP Scope 
- Let Player 1 enter a hidden 5-letter word
- Let Player 2 make six guesses
- Every guess and the hidden word has to be 5 letters and in the word list
- Green, yellow, and gray feedback after each guess
- Win and lose message with the actual word
- Let players switch roles and keep playing

## Future Plans
- Game modes like first to three wins
- Show which letters were already used
- Keep score across rounds

## Tech Stack
